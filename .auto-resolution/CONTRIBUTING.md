# Contributing

Start with an [issue](https://github.com/Timpan4/kubecove/issues). Describe user impact, expected behavior, and smallest useful scope before proposing a change.

Follow [development setup](docs/development-workflow.md) and run checks from [Verification Before Completion](docs/development-workflow.md#verification-before-completion).

## Documentation

Maintainers own repository documentation and public Wiki edits. Readers should [report a documentation issue](https://github.com/Timpan4/kubecove/issues/new?template=documentation.yml).

## Security

Do not report vulnerabilities in public issues. Follow [security policy](SECURITY.md).
