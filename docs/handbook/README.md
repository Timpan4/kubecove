# Engineering Handbook

The handbook defines code organization, file size, hygiene, and design conventions.

## Pages

- [code-organization.md](code-organization.md): where frontend, backend, and support code belongs.
- [file-size-and-split.md](file-size-and-split.md): soft and hard file-size caps and how to split a file.
- [hygiene.md](hygiene.md): orphan, superseded, duplicate, and dead code.
- [design-system.md](design-system.md): Svelte UI tokens and primitives.
- [pr-checklist.md](pr-checklist.md): checks to run before a PR or before calling work complete.

## Boundaries

The handbook does not define product behavior or record decisions. Use:

- [Product and architecture](../product-and-architecture.md) for product direction and app shape.
- [decisions/](../decisions/) for accepted decisions and guarded-operation contracts.
